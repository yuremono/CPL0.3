# 進捗報告テンプレート

各作業担当はこのテンプレートを使用して進捗報告を行ってください。

## 進捗報告の方法

### 1. 日報（作業終了時）

作業終了時に以下の内容を報告してください：

```
## {日付} 進捗報告 - 作業{担当ID}

### 完了したタスク
- [x] タスク1
- [x] タスク2

### 作成/更新したファイル
- `path/to/file.ts` (変更内容)

### 発生した問題
- なし

### 次の予定
- 次のタスク
```

### 2. 週報（週末）

週末に以下の内容を報告してください：

```
## {週} 週報 - 作業{担当ID}

### 今週の成果
- 完了したタスク一覧
- 作成したファイル一覧

### 今週の課題
- 発生した問題と解決策

### 来週の予定
- 予定しているタスク
- 見積もり

### 特記事項
- なし
```

### 3. ブロッカー報告（即座に）

問題が発生した場合は即座に報告してください：

```
## ブロッカー報告 - 作業{担当ID}

### 発生内容
- 問題の詳細
- 発生日時: {YYYY-MM-DD HH:mm}

### 影響範囲
- 影響している作業/機能

### 解決策
- 提案している解決策
- 必要なサポート

### 緊急度
- 高 / 中 / 低
```

## 進捗報告の提出先

1. **`docs/PROGRESS.md`** - マネージャーが確認
2. **`work-{担当ID}/progress.md`** - 各作業担当の記録用

## レポートのタイミング

- **作業完了時**: 必ず報告
- **1日以上作業した場合**: その日の終わりに報告
- **週の終わり**: 週報を提出
- **問題発生時**: 即座に報告
