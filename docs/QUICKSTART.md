# クイックスタートガイド

このガイドでは、Content Projection Layerをすぐに試す方法をステップバイステップで説明します。

## デモページを開く

開発サーバーが起動している状態で、以下のURLにアクセスしてください：

| ページ | URL | 説明 |
|--------|-----|------|
| デモページ（通常モード） | http://localhost:3000/demo | 通常表示モード |
| デモページ（プレビューモード） | http://localhost:3000/demo?mode=preview | 編集可能なプレビューモード |

## プレビューモードでできること

プレビューモード(`?mode=preview`)で以下の機能を試せます：

### 1. ホバーでハイライト

編集可能な要素にマウスを乗せると、**黄色の背景と点線枠**でハイライト表示されます。

### 2. クリックで要素を選択

ハイライトされた要素をクリックすると、要素が選択されます。

**現在の動作**: ブラウザのコンソールに要素情報が出力されます

コンソールを開く方法:
- **Windows/Linux**: `F12` または `Ctrl + Shift + I`
- **macOS**: `Cmd + Option + I`

出力例:
```javascript
{
  id: "blk_abc123...",
  role: "heading",
  content: "これは編集可能な見出しです",
  label: "メイン見出し",
  level: 2,
  editable: true,
  context: { section: "demo" }
}
```

### 3. ダブルクリックで直接編集（開発中）

現在は開発中のため、動作しません。今後の実装で有効になります。

## デモページの構成

デモページには以下のサンプルが含まれています：

1. **編集可能な見出し** - 大きなタイトル
2. **編集可能な段落** - テキスト文章
3. **編集可能なリンク** - クリック可能なリンク
4. **編集不可能な要素** - 編集が無効な例
5. **複数の要素** - 複数の編集可能要素の例

## a11y属性の確認

プレビューモード時、編集可能な要素には以下の属性が付与されています：

```html
<div
  data-cpl-id="blk_abc123..."
  data-cpl-type="heading"
  data-cpl-editable="true"
  role="heading"
  aria-level="2"
  aria-label="メイン見出し"
>
  <h2>これは編集可能な見出しです</h2>
</div>
```

これらの属性は、AIがコンテンツを理解するために使用されます。

## 開発者向けの確認方法

ブラウザの開発者ツールを使って、要素の構造を確認できます：

1. 要素を右クリック
2. 「検証」を選択
3. Elements タブで要素の属性を確認

## トラブルシューティング

### ハイライトが表示されない

- プレビューモード(`?mode=preview`)でアクセスしているか確認してください
- 開発サーバーが起動しているか確認してください

### コンソールにエラーが出る

1. 開発サーバーを再起動してください
2. ブラウザのキャッシュをクリアしてください（`Cmd+Shift+R` または `Ctrl+Shift+R`）

### ページが表示されない

- URLが正しいか確認してください（`/demo` または `/demo?mode=preview`）
- `npm run dev` で開発サーバーが起動しているか確認してください
